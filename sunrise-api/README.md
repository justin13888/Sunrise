# Sunrise API

Sunrise API is the backend for the Sunrise productivity app. It is built with Rust and the Actix web framework for high performance and scalability. It is designed to be a RESTful API that can be used by any frontend client, including the Sunrise web and desktop clients.

## Features

- **High Performance**: Sunrise API is built with Rust and Actix, which are known for their high performance and scalability.
