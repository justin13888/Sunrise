# Sunrise App

Desktop and web (PWA) client.

## Setup

1. Install [Bun](https://bun.sh/).
2. Install dependencies: `bun install`
3. Run the app:

    ```bash
    bun dev # For web (PWA)
    bun run tauri dev # For desktop
    bun run tauri android dev # For Android
    bun run tauri ios dev # For iOS
    ```
